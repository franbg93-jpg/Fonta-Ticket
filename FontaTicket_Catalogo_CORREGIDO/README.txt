FontaTicket — catálogo corregido: VARIANTES REPARADAS

Se ha reconstruido el sistema de variantes usando un único registro padre por familia lógica y las referencias como variantes. Se eliminaron los registros planos que provocaban repetición visual.

Reglas aplicadas:
- Las variantes solo agrupan productos realmente equivalentes (misma familia/modelo y diferencias de medida/conexión/configuración).
- Sifones T-55/T-56/T-57/T-58: cada modelo es un padre y Ø70/Ø115 son variantes.
- Accesorios WC se conserva como bloque original V9, sin cambios de contenido.
- No se repite ninguna referencia entre productos padre y variantes.
- Se usa el formato `nombre/precio/foto` + `variants`, compatible con el formato V9 que ya funcionaba.
